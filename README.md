## Overview

This interactive sales engineering tool models the financial and conversion impact of integrating Alma's flexible payment infrastructure (Buy Now Pay Later / Installments) for large-scale enterprise merchants. It is primarily focused on Tier-1 merchants (€10M – €1B+ GMV) and is designed to quantify the business case for E-commerce Directors, CFOs, and Growth teams.

---

## Key Features

- **Baseline Metrics Modeling:** Input current web traffic, conversion rate, and Average Order Value (AOV).
- **Dynamic S-Curve Adoption:** Models multi-month roll-out and customer adoption (Months 1–8).
- **Q4 Retail Seasonality:** Accounts for performance spikes during high-volume periods (Black Friday, Cyber Monday, Christmas).
- **Interactive Live Checkout Widget:** A real-time visual demonstration of the Alma payment widget updating installment calculations.
- **Executive Business Case Summary:** Auto-generates annual revenue uplift, incremental GMV, and total volume growth.
- **Technical Proof of Latency:** Displays real-time calculations against CTO-grade performance targets (<120ms API latency).

---

## Application Context

This project is part of a Senior Enterprise Account Executive application for Alma. It demonstrates a data-driven, value-selling approach, deep understanding of fintech metrics (AOV, Conversion, GMV), and hands-on technical fluency in simulating business cases for enterprise clients.

## Technical Details

- **Language:** HTML, CSS, JavaScript (Single-file web application).
- **Chart Library:** Chart.js for real-time visualization of S-Curve and Seasonality.
- **Frameworks:** None (Vanilla JS for ultra-low latency).
